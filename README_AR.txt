حزمة Voxel Ultra لتحسين لعبة العالم المكعب
==========================================

داخل الملف:
- 7 خامات PNG بحجم 512×512: العشب، التراب، الحجر، الخشب، الرمل، الأوراق والطوب.
- voxel-ultra-ui.css: شكل أزرار وواجهة وشريط الأدوات وزر المحفظة.
- voxel-ultra.js: تحسين خفيف للألوان والتباين وإضاءة جوية.
- README.txt: تعليمات إضافية باللغة الإنجليزية.

طريقة الاستخدام:
1. احتفظ بنسخة احتياطية من مشروع اللعبة.
2. فك ضغط الملف.
3. انسخ مجلد textures وملفي CSS وJS إلى ملفات المشروع.
4. في index.html أضف قبل </head>:
   <link rel="stylesheet" href="./voxel-ultra-ui.css">
5. وقبل </body> أضف:
   <script src="./voxel-ultra.js"></script>
6. أعد نشر اللعبة.

لتطبيق تصميم الواجهة على العناصر:
- الأزرار: vu-button
- الزر الرئيسي: vu-button vu-primary
- لوحة القائمة: vu-panel
- شريط الأدوات: vu-hotbar
- خانة الأدوات: vu-slot
- الخانة المختارة: vu-slot is-selected
- زر المحفظة: vu-button vu-wallet

مهم:
هذه حزمة بداية قابلة للدمج وليست تعديلاً سحرياً يعمل بمجرد رفعه إلى أي موقع.
يجب أن تسمح منصة صنع اللعبة بإضافة ملفات CSS وJavaScript، كما يجب ربط الخامات
بمواد البلوكات في كود اللعبة. الظلال الحقيقية والانعكاسات والجرافيك السينمائي
تحتاج إلى دعم محرك الرسومات نفسه. حجم الملف الكبير وحده لا يعني جودة أعلى.
