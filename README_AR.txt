إضافة أزرار عالم المكعبات — نسخة زرقاء
========================================
الملفات:
- controls.css : شكل أزرق لامع للأزرار الموجودة وشريط البلوكات والعصا.
- controls.js  : يحمّل ملف التنسيق ويتيح أحداثًا اختيارية للأزرار.

طريقة التركيب:
1) فك الضغط.
2) انسخ controls.css و controls.js إلى نفس المجلد الذي يوجد فيه index.html في مشروعك.
3) افتح index.html بمحرر النصوص.
4) قبل وسم </body> الأخير، أضف السطر التالي:
   <script src="./controls.js"></script>
5) احفظ وارفع الملفات المعدلة إلى GitHub Pages، ثم حدّث الموقع تحديثًا كاملًا.

مهم جدًا:
- هذه الإضافة تغيّر المظهر فقط ولا تستبدل لعبتك.
- تعمل أفضل إذا كانت أزرارك الحالية تستخدم IDs: build, dig, jump, fly, down أو أسماء classes/data-action الموضحة في CSS.
- إذا كانت الأزرار في مشروعك لا تستخدم هذه الأسماء، فستحتاج إلى تعديل المحددات في controls.css.
- أحداث cubes:build / cubes:dig / cubes:jump / cubes:fly / cubes:down هي جسر اختياري فقط؛ لكي تنفّذ وظيفة داخل اللعبة يجب ربطها بدوال اللعبة الموجودة.
- لا ترفع الملف فوق مشروعك قبل الاحتفاظ بنسخة احتياطية.
- للحصول على دمج مضمون مع أزرارك الحقيقية، ارفع ملف المشروع الأصلي ZIP؛ عندها يمكن تعديل index.html نفسه بدل الاعتماد على أسماء عامة.
