عالم المكعبات - تطبيق ويب يُثبَّت على الهاتف

1) ارفع كل ملفات هذا المجلد كما هي إلى أي استضافة مجانية بعنوان https
   (مثل Netlify Drop أو GitHub Pages أو Cloudflare Pages).
2) افتح الرابط في Chrome على الأندرويد (أو Safari على الآيفون).
3) اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
4) افتح اللعبة مرة واحدة مع الإنترنت لتُحفظ، وبعدها تعمل بدونه.
